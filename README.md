# Digital Image Processing

This repository contains a collection of digital image processing laboratory exercises, assignments, and supporting materials developed during coursework. The projects focus on fundamental image operations, image enhancement, filtering, and practical experimentation with Python-based image processing workflows.

## Repository Structure


## Labs Included

### Lab 1
- Basic image processing fundamentals
- Reading, displaying, and manipulating image data
- Converting images to grayscale and black-and-white
- Working with RGB images and simple image-processing scripts
- Includes both Python code and a Jupyter notebook

### Lab (2 & 3)
- Contains the combined exercises for the second and third laboratory sessions
- Focuses on additional image-processing concepts and practical assignments

### Lab 4
- Research-oriented material related to image filtering and denoising
- Includes a paper: "Yin Side Window Filtering" (CVPR 2019)
- Useful for understanding advanced filtering techniques in image processing

### Lab 5
- Additional coursework or project work for later image-processing tasks

## Tools and Technologies

This repository primarily uses:
- Python
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/husnainahmed971/Digital-Image-Processing.git
   ```

2. Navigate to the project folder:
   ```bash
   cd Digital-Image-Processing
   ```

3. Open the Python scripts or notebook files in the relevant lab folder:
   ```bash
   jupyter notebook
   ```

4. Run the scripts in Python for image processing tasks.
